# 简介
这是一个基于ASIO技术的电脑扩音器，采用C#编写。由于低延迟特性，可将该软件用于BeatBox练习，该软件可充当监听耳机的作用。

## 为什么要做这个软件？
其实我曾经也是一个BBOX爱好者,我在初中时期就接触到了BBOX，第一次在电视上看到这么神奇又酷炫的表演，有被深深震撼到并且有想学习它的冲动，这股冲动
持续到了高中，我在高中时期很幸运，也遇到了一个BBOX爱好者，我们相谈甚欢，好像很久没见的知己，我们甚至创建了BBOX社团，虽然我觉得我并没有做好副社长，
但我们也共同经历了很多与众不同的经历（上台表演，教学传播），我很庆幸我会BBOX，它给我普普通通的一生增添了一丝色彩。  
好像跑题了哈哈，世事无常，我现在居然是一名普通的程序员，其实在高中时期，我就遇到过一个问题让我困惑：怎样才能让电脑像手提音响一样，插上麦克风就能实时扩音了呢？
（注意“实时”，不是麦克风设置里应用那个"侦听此设备"，那玩意也有延迟）  
我在学习计算机时，也研究过一阵子音频技术（directsound，FMOD等），但均以失败告终。但是就在上个月（2024.9），我在研究如何DIY电子鼓时，发现NAudio库
的ASIO技术延迟很低，低到感觉不出有延迟，于是我想，能不能利用ASIO来做一个电脑扩音器呢？  
很幸运，经过我的不断尝试，NAudio库的ASIO确实能实现电脑扩音器，完全可以用来BeatBox练习，我在我的个人电脑上已经开启了从所未有的体验，没想到真的可以不用
额外买独立声卡，也不需要买好贵的音响，仅仅一台电脑和一个麦克风，就能实时监听自己通过麦克风发出的声音。  
目前这个软件还有些缺陷，因为每台个人电脑的音频外设都不一样，声卡也可能有所区别，软件还没有针对性地做兼容，我想让所有的BBOX爱好者们都能享受到这个有趣的体验，
同时也降低了大家练习BBOX的经济成本。
